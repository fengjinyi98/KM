# KM System V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个以 Markdown 为真相源、以 SQLite 为索引层、支持显式触发与渐进式披露的 KM（Knowledge + Memory）本地知识库系统，并提供可在 Codex 中使用的轻量插件入口。

**Architecture:** 采用“Markdown 真相源 + Python 核心逻辑 + SQLite FTS 索引 + Codex 插件壳”的分层方案。所有正式内容写入本地 Markdown 文件并由 Git 管理，SQLite 仅负责检索与排序；插件只负责触发 Capture / Update / Recall / Reveal 流程，不承担主存储职责。

**Tech Stack:** Python 3、SQLite FTS5、PyYAML、pytest、Codex repo-local plugin

    if any(token in text for token in PROJECT_HINTS):

    return "inbox"

```python
def recall_notes(indexer, query: str, detail_level: str = "summary") -> list[dict]:
    rows = indexer.search(query)
    results = []
    for row in rows:
        item = {
            "doc_id": row["doc_id"],
            "title": row["title"],
            "summary": row["summary"],
            "source_path": row["source_path"],
        }
        if detail_level in {"detail", "full"}:
            item["body"] = row["body"]
        results.append(item)
    return results
```
