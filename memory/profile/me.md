# me

## 当前画像
- 我是结果导向的比赛型实践者，会为了最终计分目标快速调整策略，不执着于最初方案。
- 我重视方法论沉淀、文档归档、可演示性和可恢复性，认为“能稳定复现”与“能讲清楚为什么”同样重要。
- 我偏好把复杂问题拆成 **资产 / 能力 / 路径** 三层：先定义要什么，再决定拿什么。
- 我愿意投入服务器、代理池、邮箱服务等基础设施成本，以提升比赛成功率和稳定性。
- 我重视真实验证、A/B 测试、日志、证据链，不喜欢纯猜测和无证据修补。
- 输出风格偏好：中文、直接、可执行、结论先行。

## 工作方式偏好
- 优先做最短闭环，再扩大覆盖面。
- 先做控制面与观测，再优化执行面细节。
- 遇到源头难打时，会优先考虑改中间层或消费端去适配已有资源。

## 后续补充
- 待继续积累更多比赛案例与基础设施建设偏好。
